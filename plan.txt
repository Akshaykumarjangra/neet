1. Identify `N+1` query in `server/chat-routes.ts`. Specifically, inside `GET /threads`, we are fetching `threads` from the database and then looping over them with `Promise.all(threads.map(async (thread) => { ... await db.select().from(chatMessages) ... }))`. This results in `1 + N` database queries where `N` is the number of threads.
2. We can optimize this by batch-fetching the latest message for each thread, or by joining the `chatMessages` table. However, since we just want the *latest* message per thread, using `inArray` to fetch the distinct messages for the thread IDs is a good approach. A common trick is using `selectDistinctOn` if supported, or just getting all messages matching the thread IDs sorted, but a faster way as per memory is to use `.leftJoin` or `selectDistinctOn`.
3. Wait, Drizzle ORM supports `selectDistinctOn`. We have this memory note: `When fetching the latest associated record for a batch of items in Drizzle ORM (e.g., resolving an N+1 query for latest chat messages), use db.selectDistinctOn([table.foreignKeyId]).from(table).where(inArray(table.foreignKeyId, ids)).orderBy(table.foreignKeyId, desc(table.createdAt)) to perform a single batched query efficiently.`
