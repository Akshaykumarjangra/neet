## 2025-03-09 - O(N^2) bottlenecks via Array.find() inside map() loops
**Learning:** Found two significant algorithmic bottlenecks in backend routes (`server/mock-test-routes.ts` and `server/rank-predictor-routes.ts`) where arrays were being mapped and transformed by using `Array.prototype.find()` on large datasets inside the loop. For `orderedQuestions` generation with arrays of ~200 items, this resulted in an O(N^2) performance issue. Testing revealed this was a ~40ms operation that could be reduced to ~1ms.
**Action:** Always check loop structures for nested linear lookups. Replace `Array.prototype.find()` inside loops with pre-computed `Map` objects (`new Map(data.map(item => [item.id, item]))`) to convert O(N^2) complexity to O(N + M) complexity, providing O(1) lookups on subsequent iterations.
