## 2024-03-01 - [Avoid N+1 queries in Session loops via inArray]
**Learning:** Found a classic N+1 bottleneck in `server/ws/testSessionManager.ts` where a loop iterated over questionIds and performed a database `.select()` query for each single question. This severely degraded WebSocket performance on test completion. Furthermore, many ORMs (including Drizzle) will crash if you use `inArray` with an empty array.
**Action:** When querying lists of entities based on array of IDs (like session test questions), always fetch them in a single batch using `inArray(col, array)`. Protect the Drizzle query with an `if (array.length > 0)` check. Afterwards, map the results to a `Map` structure for fast O(1) correlation back to the original loop iteration to maintain the expected O(N) loop complexity without nested search operations.
