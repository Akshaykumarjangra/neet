## 2024-05-12 - ReactMarkdown Plugin Array Memoization\n**Learning:** ReactMarkdown plugins passed as inline arrays (e.g. `remarkPlugins={[remarkGfm]}`) create new array references on every render, causing expensive child components to re-render. This is particularly problematic in interactive components like `ChapterChatbot`.\n**Action:** Always define markdown plugin arrays as module-level constants (e.g. `const markdownRemarkPlugins = [remarkGfm];`) outside the React component to maintain referential equality across renders.
