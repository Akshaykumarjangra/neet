## 2026-08-13 - [Performance improvement] - Resolving N+1 database queries in `getUserStats`
**Learning:** Fetching full related content tables inside a loop in Node.js instead of utilizing database-level SQL queries (like `.innerJoin` and `.groupBy`) leads to massive N+1 query bottlenecks. In this specific app architecture, `.getUserStats()` fetched the user attempts, and for each attempt fetched the topic & subject iteratively which took 99 seconds for 200 items. Using aggregated SQL grouped by subject took only ~0.5s.
**Action:** When determining counts or basic metrics of related database records in Drizzle ORM, always construct database-level SQL aggregations via `.leftJoin` or `.innerJoin` and `.groupBy()`, returning a single dataset instead of instantiating loops.
