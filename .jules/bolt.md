## 2024-05-18 - Nested Array.find() Performance Bottleneck\n**Learning:** Found an O(N^2) bottleneck in `server/mock-test-routes.ts` during mock test generation where it looked up questions via `Array.find()` inside a `.map()` array of IDs. For mock tests containing 100-200 questions, this blocks the event loop.\n**Action:** Pre-compute a `Map` from the array and use `Map.get()` to turn O(N*M) lookup into O(N) when merging related arrays in large list transformations.
