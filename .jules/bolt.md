## 2026-06-26 - O(N²) Lookups in Backend APIs\n**Learning:** Found O(N²) performance bottlenecks caused by calling `Array.find()` inside `Array.map()` or `for` loops in backend API routes (e.g., `server/rank-predictor-routes.ts` and `server/mock-test-routes.ts`) for processing query results.\n**Action:** When merging database results with request arrays, pre-compute a `Map` (e.g., `new Map(data.map(item => [item.id, item]))`) for O(1) lookups rather than using nested `Array.find()` to avoid O(N²) performance bottlenecks.
