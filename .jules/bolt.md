## 2026-06-19 - [Avoid O(N^2) loops with Map]\n**Learning:** When using `.map()` or loops over arrays that need to find elements in another array using `.find()`, it results in an O(N^2) operation, causing performance bottlenecks especially when array sizes grow.\n**Action:** Always prefer to pre-compute a `Map` keyed by the identifier (e.g., `new Map(array.map(item => [item.id, item]))`) for O(1) lookups inside the loop, turning the O(N^2) operation into O(N).
