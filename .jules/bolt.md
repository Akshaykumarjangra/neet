## 2024-05-18 - Replacing map with DB side count aggregations
**Learning:** The memory mentions 'When optimizing multiple independent Drizzle ORM database count queries targeting the same table, batch them into a single query using SQL conditional aggregation... to reduce database round-trips.' Also, 'When resolving N+1 database queries in Drizzle ORM (e.g., executing db.select() inside a loop), replace the nested queries and loop with a single batched query using .leftJoin() or .innerJoin() to drastically improve backend execution performance.' and 'When determining the count of related records in Drizzle ORM, always use database-level aggregations (e.g., COUNT() with .leftJoin() and .groupBy()) rather than fetching entire associated datasets into memory to read their .length property'
**Action:** Replaced Promise.all(allTopics.map(async ... db.select({count: sql...}))) pattern with a leftJoin + groupBy + COUNT aggregator in server/admin-content-routes.ts to resolve N+1 queries.
